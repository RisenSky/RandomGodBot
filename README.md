# RandomGodBot

**RandomGodBot ([@random](https://t.me/random?start=github))** — бесплатный бот для розыгрышей в Telegram-каналах и чатах. Работает с 2020 года: проверяет подписку на несколько каналов, отсекает накрутку и случайным образом выбирает победителей.

- Бот: [t.me/random](https://t.me/random?start=github) · второй адрес — [@RandomGodBot](https://t.me/RandomGodBot?start=github)

[English version below](#english)

## Что умеет RandomGodBot

- Публикует пост с розыгрышем: текст, фото, видео или GIF.
- Проверяет подписку участников на все каналы-организаторы.
- Отсекает подозрительные аккаунты и накрутку.
- Выбирает одного или нескольких победителей случайным образом.
- Публикует итоги в назначенное время — в том же посте или отдельным сообщением.
- Позволяет подписать кнопку участия своими словами.
- Участие — по кнопке через мини-приложение Telegram прямо из поста, без перехода в бота.
- Работает и в каналах, и в чатах.

## Как проходит розыгрыш

1. Организатор открывает [бота](https://t.me/random?start=github) и добавляет его в канал администратором — без прав бот не опубликует пост и не проверит подписку.
2. Создаёт розыгрыш: текст, приз, число победителей, дату итогов, каналы для подписки.
3. Бот публикует пост с кнопкой участия.
4. Участник нажимает кнопку, бот проверяет подписку и записывает участника.
5. В назначенное время бот случайным образом выбирает победителей и публикует итоги. Если победитель не выходит на связь, организатор может выбрать другого.

## Об этом репозитории

Здесь лежит **публичная версия кода RandomGodBot** (последнее обновление кода — май 2024). Боевая версия, которая сейчас работает в Telegram, может отличаться.

| Файл | Назначение |
|---|---|
| `main.py` | точка входа, обработчики команд и сценариев |
| `app.py` | инициализация бота, машины состояний и базы |
| `models.py` | модели данных (SQLAlchemy) |
| `base.py` | обёртка над запросами к базе |
| `fsm.py` | машина состояний диалогов |
| `keyboard.py` | клавиатуры и кнопки |
| `middleware.py` | промежуточная обработка сообщений |
| `tool.py` | вспомогательные функции: язык, кнопки |
| `config.py` | настройки: токен бота, адрес базы данных, канал |
| `RU.json`, `ENG.json` | тексты интерфейса на русском и английском |

Стек: Python, [pyTelegramBotAPI](https://github.com/eternnoir/pyTelegramBotAPI), SQLAlchemy.

Для запуска своей копии заполните `config.py`: токен бота от @BotFather, строку подключения к базе данных (`db_url`) и канал.

## Частые вопросы

**Сколько стоит RandomGodBot?** Бот бесплатный.
**@random и @RandomGodBot — один бот?** Да, это два адреса RandomGodBot.
**Кто выбирает победителя?** Бот, случайным образом среди участников, выполнивших условия.
**Где публикуются итоги?** В том же посте с условиями или отдельным сообщением — на выбор организатора.
**Работает ли бот в чатах?** Да, и в каналах, и в чатах.
